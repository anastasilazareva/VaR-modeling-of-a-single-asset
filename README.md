# VaR-modeling-of-a-single-asset
## Моделирование VaR одного актива

Проект посвящен оценке финансовых рисков (Value at Risk (VaR) и Expected Shortfall (ES)) для российских акций (GAZP, SBER, LKOH, ROSN). В рамках проекта реализованы и сравнены различные статистические и эконометрические подходы к моделированию хвостов распределения доходностей.

## Реализованные методы
1. Историческое моделирование (Historical Simulation): Базовый эмпирический подход.
2. Параметрические методы:
   - Нормальное распределение.
   - Распределение Стьюдента (учет тяжелых хвостов).
3. Теория экстремальных значений (EVT):
   - Блочные максимумы (Generalized Extreme Value Distribution, GEV).
   - Превышения над порогом (Peaks Over Threshold, POT / Generalized Pareto Distribution).
4. Модели волатильности:
   - GARCH(1,1) с различными распределениями остатков.
   - FIGARCH(1,1,2) (для учета эффекта долгой памяти волатильности).
5. Продвинутые и гибридные подходы:
   - Обратное гауссовское распределение (Normal Inverse Gaussian, NIG).
   - Комбинация GARCH + EVT.
   - Фильтрованная историческая симуляция (Filtered Historical Simulation, FHS).
## Бектестинг
Оценка качества моделей проводится с помощью биномиального теста (проверка доли выбросов / "hits" относительно целевого уровня α, в 5.0%).
