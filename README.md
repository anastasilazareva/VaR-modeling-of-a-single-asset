# VaR-modeling-of-a-single-asset
## Моделирование VaR одного актива

Проект посвящен оценке финансовых рисков (Value at Risk — VaR и Expected Shortfall — ES) для российских акций (GAZP, SBER, LKOH, ROSN). В рамках проекта реализованы и сравнены различные статистические и эконометрические подходы к моделированию хвостов распределения доходностей.
